# Splender ～小鳥～

宝石を集めて発展カードを買い、先に15点を目指す2人用ボードゲームです。
CPU対戦（CPU Lv1〜4）と、同じ画面での2人対戦ができます。はじめての人は、開始画面の「チュートリアル」で遊び方をおぼえられます。

**遊ぶ**：https://okalogzzm.github.io/gemrush/

スマホでは「ホーム画面に追加」すると、アプリのように全画面で開けて、電波がなくても遊べます。

## 開発

Node.js 22.18 以上が必要です。

```bash
npm install
npm run dev     # http://localhost:5173
npm run check   # 型チェック・テスト・ビルド
```

くわしくは `仕様書.md` と `CLAUDE.md` を見てください。
